# LinkPLCByMQTT 汉化说明

- **来源**：家族自有插件（USCADA 系列，MQTT 通信原语层，libmosquitto 2.1.2 + OpenSSL 3.5.x）。纯 C++，无资产，无编辑器模块；主模块 `LinkPLCByMQTT` + ThirdParty 库模块 `LinkPLCByMQTTLibrary`（不参与本地化）。
- **本地化模式**：官方 locres 注入模式（见家族 `插件优化.md` 第 25 条），自包含构建脚本直写 locres，不跑 GatherText commandlet。

## 改动清单

- `.uplugin`：新增 `LocalizationTargets` 块（Name=LinkPLCByMQTT，LoadingPolicy=Editor，ConfigGenerationPolicy=Never）——不声明则 locres 静默不加载；
- 新增 `Config/Localization/build_linkplcbymqtt_localization.py`（551 行模板的多 namespace 适配版：CityHash64/locres v3 直写 + verify 模式 + `FName::NameToDisplayString` Python 移植，全部拷自家族模板，无外部依赖）；
- 新增 `Content/Localization/LinkPLCByMQTT/`：manifest + en/zh-Hans archive + zh-Hans PO + en/zh-Hans locres + locmeta（locres 格式版本 Optimized_CityHash64_UTF16 = 3）；
- **源码改动：无**。全模块 grep 核实不存在任何 `LOCTEXT`/`NSLOCTEXT`/`INVTEXT`/`FText::FromString` 界面字符串（`LinkPLCByMQTT.cpp` 里只有一个未使用的 `LOCTEXT_NAMESPACE` 宏定义骨架），无需 INVTEXT→NSLOCTEXT 机械替换；Manager 的错误文本走 `FString`（`GetLastErrorMessage`），不在 FText 本地化管线覆盖范围内，保持原样。

## 汉化条目（共 43 条）

| namespace | 条数 | 内容 |
| --- | --- | --- |
| `UObjectDisplayNames` | 41 | 1 个 UCLASS 类名（`LinkPLCByMQTTBPLibrary`）+ 18 个蓝图函数名 + 1 个 USTRUCT 结构体名（`MQTTConnectOptions`）+ 18 个属性名 + 3 个枚举值（`EMQTTQoS`） |
| `UObjectCategory` | 2 | `MQTT`、`LinkPLCByMQTT`（均为品牌段，译文保留英文，注入仅为显式锁定行为） |

- key 规则：UHT 剥前缀（`ULinkPLCByMQTTBPLibrary`→`LinkPLCByMQTTBPLibrary`、`FMQTTConnectOptions`→`MQTTConnectOptions`）；属性/函数 key = `<类名>:<名>`，枚举值 key = `<枚举名>.<值名>`（坑 #4）；**枚举名带 E 前缀**（`EMQTTQoS.AtMostOnce`——坑 #26，Charts 无头探针 probe_enum_result.txt 3/3 实测，与类/属性的剥前缀规则相反）；
- source 规则：显示名类条目 source = `NameToDisplayString` 计算值（脚本现场计算，参与 CRC32 校验，错一字节回退英文）；**枚举值 source = `UMETA(DisplayName)` 原文**（坑 #5：有元数据时 source 取元数据原文）——本插件枚举 DisplayName 本身就是中文混排（如 `QoS 0 - 最多一次 (At Most Once)`），英文环境显示因此保持与现状一致，zh-Hans 译文去掉英文括注（`QoS 0 - 最多一次`）；
- 注意 `NameToDisplayString` 对连续大写 run 不做二次拆词，引擎计算值即本表 source，如 `LWTQoS`→`LWTQo S`、`MQTTConnectOptions`→`MQTTConnect Options`、`LinkPLCByMQTTBPLibrary`→`Link PLCBy MQTTBPLibrary`——看似怪异但与运行时逐字节一致，属预期；
- tooltip：全家族 tooltip 源为 `/** */` 横幅注释（本插件属性注释齐全但无 meta ToolTip），**不做 tooltip 注入**，属性悬浮提示维持引擎默认行为。

## 术语表

- broker/broker = broker（不译）；topic = 主题；payload = 内容/消息；retain = 保留消息
- LWT（Last Will and Testament）= LWT 遗嘱（家族统一译法）；Clean Session = 清理会话；persistent session = 持久会话
- QoS 0/1/2 = 最多一次 / 至少一次 / 恰好一次（对应 AtMostOnce/AtLeastOnce/ExactlyOnce）
- TLS = TLS 加密（不译缩写）；CA 证书 / 客户端证书 / 客户端私钥 = CA Cert / Client Cert / Client Key；PEM = PEM（不译）
- bundle = 内置 CA 证书 Bundle；Pump = 驱动网络循环（Pump 保留原词）
- 品牌段保留英文：MQTT、LinkPLCByMQTT、QoS、LWT、CA、PEM、ID

## 踩坑记录

- 本插件无坑新增。沿用的家族既定坑：#4（UHT 前缀剥除，类/属性 key 剥 `U`/`F`；**枚举值 key 不剥 E**，见 #26）、#5（有 DisplayName 元数据时 source 取元数据原文——本插件枚举值即此形态）、#25（≤20 条最小管线，locres 离线直写）、#26（枚举值 key 带 E 前缀，Charts 无头探针 probe_enum_result.txt 3/3 实测）。
- 维护约定：新增/修改文案 → 改脚本 ENTRIES → 重跑脚本 → 重启编辑器；**勿对本插件跑完整 Gather 收集**（外部插件目录收集为零，空 manifest 会冲掉注入内容）。
